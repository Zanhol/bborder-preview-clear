# bb点单预览版 · 详细部署清单（从零开始）

> 适用仓库：`bborder-preview-clear`（开源版）
> 版本：2026-09-06 · 版权：© 2026 深圳市甜梦屋科技有限公司 · Apache-2.0
> 目标：在一台 Windows 电脑上从零安装依赖，跑通「老公下单 → 老婆收通知 → 老婆做菜 → 老公收通知」完整闭环。

## 0. 架构与端口总览

| 组件 | 说明 | 端口 |
|---|---|---|
| MySQL 8.4 | Docker 容器 `bbopen-preview-mysql` | 宿主 3318 → 容器 3306 |
| 后端 Spring Boot | Docker 容器 `bbopen-preview-backend` | 8088 |
| nginx | Docker 容器 `bbopen-preview-nginx`（统一入口） | 8080 |
| 前端 | uni-app 编译微信小程序，由微信开发者工具导入 | 无端口（小程序） |
| 数据库 | `family_meal`，后端首启自动建表 + 幂等种子 | — |

## 1. 安装依赖（Windows）

### 1.1 JDK 17
- 下载：Eclipse Temurin 17（https://adoptium.net/ ，选 Windows x64 MSI）
- 安装后验证：
```powershell
java -version   # 应显示 openjdk version "17.x"
```
- 配置 `JAVA_HOME`：系统属性 → 环境变量 → 新建 `JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot`，并把 `%JAVA_HOME%\bin` 加入 `Path`。

### 1.2 Maven 3.9
- 下载：https://maven.apache.org/download.cgi （Binary zip）
- 解压到 `C:\tools\apache-maven-3.9.x`，把 `bin` 加入 `Path`。
```powershell
mvn -v   # 验证
```

### 1.3 Node.js 22 + npm
- 下载：https://nodejs.org/ （LTS，Windows x64 MSI）
```powershell
node -v; npm -v
npm config set registry https://registry.npmmirror.com   # 国内加速（可选但推荐）
```

### 1.4 Docker Desktop
- 下载：https://www.docker.com/products/docker-desktop/ （含 WSL2 后端）
- 安装后启动 Docker Desktop，等待引擎就绪：
```powershell
docker version
docker compose version
```
- ⚠️ 若本机有代理软件（如 Clash），注意：Docker Desktop「Settings → Resources → Proxies」若填了 `127.0.0.1:7897` 等地址，该代理必须保持开启，否则容器无法访问外网（拉镜像、微信 API 都会失败）。

### 1.5 微信开发者工具
- 下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html （Windows x64 稳定版）
- 安装后用微信扫码登录（需是小程序管理员/开发者）。

### 1.6 Git
- 下载：https://git-scm.com/download/win
```powershell
git --version
```

### 1.7 Tailscale（可选，用于公网域名联调）
- 下载：https://tailscale.com/download/windows
- 登录后启用 Funnel（供真机通过 `https://<你的机器>.ts.net` 访问本机 8088，正式上线不用）。

## 3. 配置后端环境变量

```powershell
Copy-Item docker\.env.example docker\.env
# 编辑 docker\.env：
```

| 变量 | 说明 | 必填 |
|---|---|---|
| `MYSQL_PASSWORD` | MySQL root 密码；留空=容器空密码 | 否 |
| `JWT_SECRET` | 后端签名密钥，**≥32 个 ASCII 字符** | ✅ 必填 |
| `DEMO_ENABLED` | `true` 时开启 H5 免密登录与演示数据（无微信凭据体验用） | 否 |
| `WECHAT_APPID` | 小程序 AppID | 微信登录必填 |
| `WECHAT_SECRET` | 小程序 Secret | 微信登录必填 |
| `WECHAT_TEMPLATE_ID` | 订单通知模板 ID（字段：订单号/菜名/时间/辣度） | 通知必填 |
| `WECHAT_TEMPLATE_COOK_DONE_ID` | 订单完成模板 ID（字段：完成时间 date7 / 温馨提示 thing5） | 通知必填 |
| `ADMIN_PASSWORD` / `ADMIN_RESET_KEY` | 管理口令 / 重置身份密钥，留空禁用 | 否 |

生成 JWT_SECRET（PowerShell）：
```powershell
-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 64 | ForEach-Object {[char]$_})
```

## 4. 构建并启动后端（Docker）

```powershell
cd backend
mvn package -DskipTests      # 生成 target/family-meal-backend-1.0.0.jar
cd ..
docker compose -f docker/compose.yml up -d --build
```

验证：
```powershell
docker ps --filter name=bbopen-preview   # 三个容器 Up，mysql healthy
curl http://localhost:8088/api/categories
# 期望：返回 2 个分类（买菜做饭/懒人外卖）+ 9 个子分类
```

数据库首次启动自动执行 `backend/src/main/resources/db/init.sql`（建 7 张表 + 分类/子分类/夫妻席位种子）。

## 5. 构建前端小程序

```powershell
cd frontend
npm ci
npm run build:mp-weixin
```

- 产物：`frontend/dist/build/mp-weixin`
- 微信开发者工具 → 导入项目 → 选择 `frontend` 目录（`project.config.json` 已配 `miniprogramRoot=dist/build/mp-weixin/`）。
- 把 `frontend/project.config.json` 与 `frontend/src/manifest.json` 两处的 `appid` 改成你的小程序 AppID。

---

## 6. 微信公众平台配置

1. **订阅消息模板**（功能 → 订阅消息）申请两个：
   - 订单通知：`character_string1`(订单号) + `thing2`(菜名) + `time4`(时间) + `thing9`(辣度)
   - 订单完成：`date7`(完成时间) + `thing5`(温馨提示)
2. 把模板 ID 分别填入 `docker/.env` 的 `WECHAT_TEMPLATE_ID` 与 `WECHAT_TEMPLATE_COOK_DONE_ID`，前端 `frontend/src/store/auth.js` 的 `tmplIds` 同步两个 ID。
3. 重启后端使 `.env` 生效，重新 `npm run build:mp-weixin` 并上传体验版。

## 7. 域名与真机联调

| 场景 | 前端 BASE_URL（`frontend/src/api/request.js` 等） | 说明 |
|---|---|---|
| 开发者工具模拟器 | `http://127.0.0.1:8088` | 勾选「不校验合法域名」 |
| 真机体验版 | `https://<你的机器>.ts.net`（Tailscale Funnel）或你的备案 HTTPS 域名 | 体验版右上角「…」→「打开调试」跳过域名校验 |
| 正式上线 | 备案域名（如 `tianmwsys.net`） | 微信后台登记 request/uploadFile/downloadFile 三类合法域名（裸域名，不带协议） |

⚠️ `*.ts.net` 无法 ICP 备案，只能测试用；正式上线必须备案域名 + HTTPS。

## 8. 全流程业务验证

1. 两个微信分别登录（第一个占「老公」席位、第二个占「老婆」席位；同一微信重复登录复用席位）。
2. 老公端下单 → 老婆微信收到「订单通知」。
3. 老婆订单页「标记已收到」→ 老公微信收到「已收到」通知。
4. 老婆菜品页点「做完饭了」→ 老公微信收到「饭好了」通知，老公菜单页显示「饭好啦」横幅。

接口自测：
```powershell
curl http://localhost:8088/api/cook/current   # {"cookWho":"wife","cookStatus":"cooking"}
curl http://localhost:8080/api/categories     # nginx 反代 200
```

## 9. 常见坑

1. **登录名额被占**：微信凭据未配置时后端返回稳定测试 openid（只占 1 席）；换 AppID 后需 `docker exec bbopen-preview-mysql mysql -uroot family_meal -e "UPDATE users SET openid=NULL;"`。
2. **tab/子tab 不显示**：分类种子已并入 `init.sql`（幂等）且 `spring.sql.init.encoding=UTF-8`，重建库自动有；老库执行一次 `backend/src/main/resources/db/fix_categories.sql`。
3. **容器访问微信 API 失败**：Docker Desktop 注入的代理未开（见 1.4）——开代理或关闭 Docker 代理设置后重启容器。
4. **`/api/auth/me` 404**：已内置 `GET /me`、`PUT /me/background`。
5. **开发者工具改了代码不生效**：工具 → 清除缓存 → 全部清除 → 重新编译（旧编译缓存是高频坑）。

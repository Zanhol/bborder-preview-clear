# bb点单预览版 · 部署指南（电脑小白版）

> 适用仓库：`bborder-preview-clear`（开源版）
> 版本：2026-09-06 · © 2026 深圳市甜梦屋科技有限公司 · Apache-2.0
> 本指南目标：**你不需要懂代码**，照着做就能把整套系统在自己电脑上跑起来，并用两台手机（微信）完成「老公下单 → 老婆收通知 → 老婆做菜 → 老公收通知」的全流程。

---

## 0. 先认识一下：这些软件都是干嘛的

| 名词 | 一句话解释 | 在这个项目里干嘛 | 你需要做什么 |
|---|---|---|---|
| **Docker** | 一种"打包盒"软件，把程序连环境一起装进盒子 | 把 MySQL 数据库、后端、nginx 三个盒子一次跑起来 | 装好 Docker Desktop，双击运行它 |
| **MySQL** | 数据库，存数据的地方 | 存菜品、订单、夫妻账号 | 不需要直接操作（盒子自动建好） |
| **后端（Spring Boot）** | 网站的大脑，处理登录、下单、发微信通知 | 小程序所有按钮背后都是它在干活 | 跑起来就行 |
| **nginx** | 一个"门卫/接线员"，把门口 8080 的请求转给后端 8088 | 让你用同一个地址访问接口和图片 | 不用管，随盒子自动启动 |
| **Tailscale** | 让你和你的设备组成一个"私人网络"，并能给手机开一个公网网址 | 让手机在外面也能连到你电脑的后端（真机测试用） | 注册账号、登录、开 Funnel（第 9 步细讲） |
| **微信开发者工具** | 微信官方做小程序的软件 | 编译前端代码、在电脑上模拟、上传体验版到微信 | 装好、导入项目、点上传 |
| **订阅消息** | 微信的一种"服务通知" | 老婆收"下单通知"、老公收"饭好了通知" | 在微信公众平台申请两个模板（第 8 步细讲） |

> 如果你只是想让两台手机在**家里同一个 WiFi** 下用，可以不装 Tailscale（用局域网 IP 即可）。Tailscale 只在你需要"人在外面也能用"时才需要。

## 1. 安装依赖（每步都点"下一步"就行）

### 1.1 安装 JDK 17（Java 运行环境）
- **为什么**：后端程序是 Java 写的，需要 Java 才能编译运行。
- **操作**：
  1. 打开 https://adoptium.net/
  2. 点最新 **Temurin 17 (LTS)** 的 Windows x64 `.msi` 下载
  3. 双击安装，一路「Next」→「Install」→「Finish」
  4. 按 `Win + R`，输入 `cmd` 回车，黑色窗口里输入 `java -version` 回车
  5. 看到 `openjdk version "17.…"` 就成功了
- **补充**：一般不用手动配环境变量；如果后面 `mvn` 报"找不到 java"，再配 `JAVA_HOME`（网上搜"Windows 配置 JAVA_HOME"，照图点）。

### 1.2 安装 Maven（把后端代码打包成可运行文件）
- **为什么**：后端代码要"编译打包"成一个 jar 文件，Maven 就是干这个的。
- **操作**：
  1. 打开 https://maven.apache.org/download.cgi
  2. 下载 **Binary zip archive**（比如 `apache-maven-3.9.x-bin.zip`）
  3. 右键解压到 `C:\tools\apache-maven-3.9.x`
  4. 把里面的 `bin` 文件夹路径（如 `C:\tools\apache-maven-3.9.x\bin`）加到系统 `Path`：
     「设置 → 系统 → 关于 → 高级系统设置 → 环境变量 → 系统变量 Path → 新建 → 粘贴路径 → 确定」
  5. 新开一个 cmd 窗口输入 `mvn -v`，能看到版本号即成功

### 1.3 安装 Node.js（编译前端小程序）
- **为什么**：前端小程序用 uni-app 写的，需要 Node.js 来"打包"成微信能读的文件。
- **操作**：
  1. 打开 https://nodejs.org/
  2. 下载 **LTS** 版 Windows `.msi`，双击一路下一步
  3. cmd 里输入 `node -v` 和 `npm -v`，都能看到版本号即成功
  4. 建议再输入下面这行（用国内镜像，下载更快）：
     ```
     npm config set registry https://registry.npmmirror.com
     ```

### 1.4 安装 Docker Desktop（一键启动三个"盒子"）
- **为什么**：不用你分别安装和配置 MySQL、nginx、Java 服务，Docker 一条命令全部拉起。
- **操作**：
  1. 打开 https://www.docker.com/products/docker-desktop/
  2. 下载 Windows 版并安装（可能需要重启电脑，按提示来）
  3. 打开 Docker Desktop，等左下角变成绿色 `Engine running`
  4. cmd 里输入 `docker version` 能输出信息即成功
- **重要提醒（代理）**：如果你电脑装了 Clash/V2Ray 等代理软件，打开 Docker Desktop → 右上角齿轮 Settings → Resources → Proxies：如果那里填了 `127.0.0.1:7897` 之类的地址，**你的代理软件必须一直开着**，否则后端容器上不了网、微信通知发不出去。嫌麻烦就把 Proxies 里的手动代理关掉（切回默认）。

### 1.5 安装微信开发者工具
- **为什么**：微信小程序只能用这个官方软件编译、预览、上传。
- **操作**：
  1. 打开 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
  2. 下载 **Windows x64 稳定版**，安装
  3. 打开后用**小程序管理员/开发者的微信**扫码登录

### 1.6 安装 Git（下载代码用）
- **操作**：打开 https://git-scm.com/download/win 下载安装，一路下一步；cmd 输入 `git --version` 验证。

### 1.7 （可选）安装 Tailscale
- **为什么**：第 9 步细讲。先知道：**只有当你想"人在外面、用手机流量也能访问家里这台电脑"时才需要**。
- **操作**：打开 https://tailscale.com/download/windows 下载安装，用 Google/微软/GitHub 账号登录（Tailscale 免费）。

## 3. 填写后端配置（`.env` 文件）

**这是最容易被跳过的关键一步。** 后端靠这个文件知道"微信账号是什么、通知模板是什么、签名密钥是什么"。

### 操作
1. 进入 `docker` 文件夹，把 `.env.example` **复制一份**，改名为 `.env`（注意：复制出来的文件就叫 `.env`，没有后缀）。
2. 用「记事本」打开 `.env`，逐行填：

| 变量 | 填什么 | 不填会怎样 |
|---|---|---|
| `MYSQL_PASSWORD=` | 留空即可（本地测试） | 无影响 |
| `JWT_SECRET=` | 随便填一串 **32 位以上**的字母数字混合（比如 `aB3xY9kLmN8pQr2sT5uV7wZ1cD4fG6hJ0`） | 后端会启动失败 |
| `DEMO_ENABLED=` | 先填 `false` | — |
| `WECHAT_APPID=` | 你的小程序 AppID（第 8 步拿） | 微信登录失败 |
| `WECHAT_SECRET=` | 你的小程序 AppSecret（第 8 步拿） | 微信登录失败 |
| `WECHAT_TEMPLATE_ID=` | 订单通知模板 ID（第 8 步申请） | 老婆收不到下单通知 |
| `WECHAT_TEMPLATE_COOK_DONE_ID=` | 订单完成模板 ID（第 8 步申请） | 老公收不到"饭好了"通知 |
| `ADMIN_PASSWORD=` / `ADMIN_RESET_KEY=` | 留空（禁用后台口令） | 无影响 |

> 不会生成 JWT_SECRET？打开 PowerShell 粘贴这行回车：
> `-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 64 | ForEach-Object {[char]$_})`
> 把输出的一串字符填进去。

## 4. 启动后端（一条命令拉起三个服务）

1. 打开 PowerShell（开始菜单搜 PowerShell）
2. 进入项目目录：
   ```powershell
   cd C:\你的路径\bborder-preview-clear
   ```
3. 打包后端（第一次会下载依赖，等几分钟）：
   ```powershell
   cd backend
   mvn package -DskipTests
   cd ..
   ```
   看到 `BUILD SUCCESS` 就是成功。
4. 启动三个容器：
   ```powershell
   docker compose -f docker/compose.yml up -d --build
   ```
5. 检查是否都跑起来了：
   ```powershell
   docker ps --filter name=bbopen-preview
   ```
   应看到三个名字：`bbopen-preview-mysql`（healthy）、`bbopen-preview-backend`、`bbopen-preview-nginx`。
6. 验证后端活着：
   ```powershell
   curl http://localhost:8088/api/categories
   ```
   返回一串含"买菜做饭""懒人外卖"的文字就是成功。

**如果失败**：看第 12 节常见问题表。

## 5. nginx 是干嘛的？你需要操作吗？

- **解释**：你可能会想"后端已经在 8088 了，为什么还有个 8080 的 nginx？"——nginx 是**门卫**：小程序/浏览器请求统一打到 8080，nginx 再转给后端 8088，并且把 `/uploads/` 图片等静态文件也一并代理。对你来说，记住两个地址：
  - `http://localhost:8080` —— 统一入口（推荐用这个）
  - `http://localhost:8088` —— 后端直连
- **你需要操作**：**不需要**。它随 `docker compose up` 自动启动，配置在 `docker/nginx.conf`。
- **验证**：
  ```powershell
  curl http://localhost:8080/api/categories
  ```
  与 8088 返回同样内容 = nginx 工作正常。
- **多方案**：如果你不想用 nginx，也可以直接用 8088（前端 BASE_URL 填 8088 即可）；但建议保留 nginx，方便以后加 HTTPS、静态托管。

## 7. 微信开发者工具：导入、编译、上传

1. 打开微信开发者工具，微信扫码登录。

## 8. 微信公众平台全流程（AppID / 密钥 / 通知模板）

打开 https://mp.weixin.qq.com/ 用小程序管理员微信扫码登录。

### 8.1 拿到 AppID
- 「设置 → 基本设置 → 账号信息」里就是 **AppID(小程序ID)**。
- 把 AppID 填到两个地方：
  - 后端 `docker/.env` 的 `WECHAT_APPID`
  - 前端 `frontend/project.config.json` 的 `appid` 和 `frontend/src/manifest.json` 里 `mp-weixin` 的 `appid`（改完重新执行第 6 步 build）

### 8.2 拿到 AppSecret
- 「设置 → 基本设置 → 账号信息」里点「重置」生成 **AppSecret**（用管理员微信扫码确认，会显示一次，请立即复制保存）。
- 填到 `docker/.env` 的 `WECHAT_SECRET`。
- 改完 `.env` 后需要重启后端：
  ```powershell
  docker compose -f docker/compose.yml up -d
  ```

### 8.3 申请两个订阅消息模板（微信通知的关键）
微信规定：小程序给用户发"服务通知"，必须使用**订阅消息模板**，且字段是固定的。

1. 进入「功能 → 订阅消息」。
2. 点「选用」或去「公共模板库」找模板。找不到完全同名的没关系，**按字段找**：

**模板一：订单通知**（老婆收"老公下单了"）
- 找包含这些字段的模板（字段类型必须一致）：
  - `character_string` 类型（填"订单编号"用途）
  - `thing` 类型 ×2（填"菜名"和"辣度"用途）
  - `time` 类型（填"下单时间"用途）
- 常见可用模板标题："订单支付成功通知""新订单提醒""订单创建通知"等。
- 选好后记下**模板 ID**（形如 `4DcP…`）。

**模板二：订单完成**（老公收"饭好了"）
- 找包含这些字段的模板：
  - `date` 类型（填"完成时间"用途）
  - `thing` 类型（填"温馨提示"用途）
- 常见可用模板标题："订单完成通知""任务完成提醒"等。
- 记下**模板 ID**（形如 `_0yd…`）。

> 多方案：如果公共库实在找不到，可以「申请自定义模板」（类目选"生活服务/餐饮"等），填同样字段提交审核。

3. 把两个模板 ID 填到：
   - `docker/.env`：`WECHAT_TEMPLATE_ID`（订单通知）、`WECHAT_TEMPLATE_COOK_DONE_ID`（订单完成）
   - 前端 `frontend/src/store/auth.js`：找到 `tmplIds:` 两处，换成你的两个模板 ID（老公端是两个、老婆端是一个）
4. 改完重新 build 前端（第 6 步）并上传体验版（第 7 步）。

### 8.4 用户怎么授权收通知？
- 老婆第一次登录（做饭端）会弹「开启通知」，点允许 → 老婆才能收到下单通知。
- 老公第一次登录（点菜端）会弹「开启通知」，点允许 → 老公才能收到"已收到/饭好了"通知。
- 微信订阅消息是"点一次允许、能收一次通知"的机制；每次登录引导授权一次即可覆盖本次流程。

### 8.5 收不到通知怎么排查？
1. 后端日志里看 `[WeChat]` 开头内容：
   ```powershell
   docker compose -f docker/compose.yml logs -f backend
   ```
2. 常见返回码：`40029`（登录 code 无效，正常，忽略）、`43101`（用户拒绝订阅/没授权，重新登录点允许）、`40003`（openid 错误，换 AppID 后需要清空席位，见第 12 节）。

## 9. 让手机连上你的电脑（三选一）

### 方案 A：手机和电脑在同一个 WiFi（最简单，先试这个）
1. 查电脑局域网 IP：PowerShell 输入 `ipconfig`，找「无线局域网适配器 WLAN」里的 `IPv4 地址`（形如 `192.168.1.5`）。
2. 前端 `frontend/src/api/request.js`、`config.js`、`dish.js`、`admin.js`、`utils/image.js` 里的地址全部改成 `http://192.168.1.5:8088`（共 5 处，把原来的域名替换掉）。
3. 重新 build + 上传体验版；手机连同一个 WiFi；真机右上角「… → 打开调试」。
4. 缺点：出了家门就用不了。

### 方案 B：Tailscale + Funnel（人在外面也能用，免费）
**Tailscale 是什么**：给你的电脑和手机装一个"私人组网"软件，设备之间像在同一个局域网。**Funnel 是什么**：Tailscale 的免费功能，给你的电脑开一个公网 HTTPS 网址（形如 `https://pc.tail2ef6b2.ts.net`），外面任何手机都能访问。

**操作**：
1. 电脑装 Tailscale 并登录（第 1.7 步）。
2. 打开 Tailscale 图标 → 菜单里打开 **Funnel**（或命令行 `tailscale funnel 8088 on`）。
3. 记下它给你的网址（形如 `https://你的机器名.xxxxx.ts.net`）。
4. 前端 5 个文件里的地址全部改成这个网址（如 `https://pc.tail2ef6b2.ts.net`）。
5. 重新 build + 上传体验版；手机真机点「… → 打开调试」后即可使用。
6. 缺点：`*.ts.net` 无法备案，只能测试；正式上线要换方案 C。

### 方案 C：备案域名 + HTTPS（正式上线）
1. 买一个域名，完成 **ICP 备案**（在云服务商处提交，通常 1-2 周）。
2. 用 nginx 或云服务商给域名配 HTTPS 证书，把域名反向代理到你电脑/服务器的 8088。
3. 微信公众平台「设置 → 基本设置 → 服务器域名」填**裸域名**（不带 `https://`，如 `yourdomain.com`）到 request/uploadFile/downloadFile 三类。
4. 前端地址换成 `https://yourdomain.com`，build + 上传，真机不再需要"打开调试"。

## 11. 数据备份与日常维护

- **停止服务**（保留数据）：`docker compose -f docker/compose.yml stop`
- **再次启动**：`docker compose -f docker/compose.yml up -d`
- **彻底删除（会清空数据库！）**：`docker compose -f docker/compose.yml down -v`
- **数据库在容器卷里**，日常无需手动备份；要导出数据可执行：
  ```powershell
  docker exec bbopen-preview-mysql mysqldump -uroot family_meal > backup.sql
  ```

## 12. 常见问题对照表

| 现象 | 原因 | 解决 |
|---|---|---|
| 后端启动失败：`JWT_SECRET` 报错 | 密钥没填或太短 | `.env` 填 32 位以上字符串 |
| `docker compose` 提示拉镜像失败 | Docker 代理没开 / 网络问题 | 开代理，或 Docker Desktop Settings→Resources→Proxies 关掉手动代理 |
| 真机报 `request:fail url not in domain list` | 微信域名校验没过 | 真机「… → 打开调试」；正式上线换备案域名 |
| 登录提示"夫妻名额已满" | 两个席位都被占 | 清空重绑：`docker exec bbopen-preview-mysql mysql -uroot family_meal -e "UPDATE users SET openid=NULL;"` |
| 换 AppID 后登录失败 | 旧 openid 属于旧 AppID | 同上，清空 users.openid |
| tab/子tab 不显示 | 分类表没种子 | 执行 `backend/src/main/resources/db/fix_categories.sql`（老库一次即可） |
| 微信通知发不出去 | 模板 ID 没填/没授权 | 检查 `.env` 两个模板 ID；重新登录点「允许」；看后端 `[WeChat]` 日志 |
| 开发者工具改了代码没变化 | 编译缓存 | 工具 → 清除缓存 → 全部清除 → 重新编译 |
| `/api/auth/me` 404 | 旧版本后端 | 升级到本仓库最新代码（已内置该接口） |
| 菜品图片显示不出来 | 前端图片地址还是占位符 | 检查 `utils/image.js` 与 `dish.js` 的地址是否已改成你的后端地址 |

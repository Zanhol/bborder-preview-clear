# 仓库同步说明

本项目同时托管在两个平台，内容一致：

| 平台 | 地址 | 分支 |
|---|---|---|
| Gitee（国内，主推） | https://gitee.com/TianMWsys/bborder-preview-clear | `master` |
| GitHub（海外镜像） | https://github.com/Zanhol/bborder-preview-clear | `main` |

## 更新同步命令

本地仓库已配置两个远端：

- `origin` → Gitee（`master`）
- `github` → GitHub（`main`）

改完代码、提交（commit）后，依次推送两个远端：

```powershell
# 推 Gitee
git push origin master

# 推 GitHub（本地 master 对应 GitHub main）
git push github master:main
```

## 从零重新克隆

```powershell
# Gitee
git clone https://gitee.com/TianMWsys/bborder-preview-clear.git

# GitHub
git clone https://github.com/Zanhol/bborder-preview-clear.git
```

## 备注

- 两边代码必须保持一致：任何一边的更新都要同步推另一边。
- GitHub 默认分支是 `main`，Gitee 是 `master`，所以推 GitHub 用 `master:main`。
